# スタイルルール

Tailwind CSS v4 を使う。デザインの基準はモック（`.users/mock/portfolio_welcome.html`）と `.users/requirements/screens.md`。

## 基本方針

- スタイルは Tailwind のユーティリティクラスで書く
- ユーティリティで表現できないもの（Canvas周りの配置、`@property` を使うアニメーション、マスク等）のみ、コンポーネント内の `<style>` に書く
- 同じクラスの組み合わせが3か所以上に出てきたら、コンポーネントに切り出す（`@apply` でまとめない）
- インラインの `style` 属性は、JavaScriptから値を渡す場合（CSS変数の設定など）のみ使う

## デザイントークン

色・フォントなどの値は `src/styles/` の `@theme` に定義し、クラスではトークン名で参照する。16進数やRGBの値をクラスに直接書かない。

### セクションの色

各セクションのアクセント色は、RGBの3値をCSS変数で持つ（透明度を変えて使うため）。

| セクション | 変数 | 値 |
| --- | --- | --- |
| About | `--color-about` | `255 255 255` |
| Career | `--color-career` | `244 114 182` |
| Works | `--color-works` | `56 189 248` |
| Tech | `--color-tech` | `129 140 248` |
| Notes | `--color-notes` | `52 211 153` |
| Activity | `--color-activity` | `251 191 36` |

- セクション内の共通部品は、上記を直接参照せず `--accent` を参照する。`SectionLayout` がセクションに応じて `--accent` を設定する

### 背景・文字

- 背景：`#06060b`（ダークのみ。ライトテーマは用意しない）
- 文字は白の透明度で階層を付ける（本文 60〜80%、補足 40〜50%、無効 20〜30%）

### フォント

- 英字：Montserrat（見出し・ラベルは大文字 + 広めの字間）
- 日本語：OS標準のゴシック体（Webフォントを読み込まない）
- 記事本文など長い日本語は、大文字化・広い字間を使わない

## レイアウト

- スマートフォン（幅 390px 前後）から確認し、`sm:` 以上で広げる（モバイルファースト）
- 本文の最大幅は `max-w-3xl`
- 横スクロールを発生させない（タブの行など意図したものを除く）

## アニメーション

- すべてのアニメーション・トランジションは `prefers-reduced-motion: reduce` で無効化または簡略化する
- ホバーで要素の大きさ・行の高さを変えない（レイアウトのずれ・ちらつきを防ぐ）
