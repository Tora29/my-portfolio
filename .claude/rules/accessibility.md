# アクセシビリティルール

## 目標

**WCAG 2.1 レベル AA** を満たす。

- AAA は、サイト全体では目標にしない（W3C もサイト全体への適用は推奨していない）
- AAA のうち、デザインを大きく変えずに入るもの（動きの停止、フォーカスの見やすさなど）は、できる範囲で入れる

## コントラスト（1.4.3 / 1.4.11）

背景 `#06060b` の上に、白の透明度で文字を書く（`styling.md`）。透明度ごとのコントラスト比は次のとおり。

| 白の透明度 | コントラスト比 | 使ってよいもの |
| --- | --- | --- |
| 50% 以上 | 5.31 以上 | すべての文字 |
| 35〜45% | 3.09〜4.47 | 大きい文字（24px 以上、または太字 18.66px 以上）、UI 部品の枠・フォーカスの表示 |
| 35% 未満 | 3.09 未満 | 飾り（区切り記号・罫線）、押せない部品のみ |

- 読む必要のある文字は、補足・日付・ラベルであっても 50% 以上にする（小さい文字を薄くしない）
- 件数 0 の表示や「まだありません」も情報なので、文字として扱う
- セクションのアクセント色は、背景の上ですべて 4.5:1 以上ある（最も低い Tech で 6.78）。文字に使ってよい。新しい色を加えるときは、同じく 4.5:1 以上あるか確かめる
- 画像や Canvas の上に文字を置くときは、背景を暗くする（Home の名前の周りのぼかしのように）

## キーボード操作（2.1.1 / 2.4.3 / 2.4.7）

- すべての操作をキーボードで行えるようにする。押せるものは `<a>` か `<button>` にする（`<div>` に `onclick` を付けない）
- フォーカスの表示を消さない。`focus:outline-none` を使うときは、代わりに `focus-visible:` で見える印（リングや色の変化）を付ける
- 押したボタンが消える・入れ替わるとき（「もっと見る」「+N」など）は、フォーカスを切り替え先へ移す
- タブ順は見た目の順と揃える

## 動き（2.2.2 / 2.3.3）

- 自動で始まり5秒以上続く動き（Home の宇宙のシーン）には、止める手段を用意する（2.2.2。レベル A）。OS の `prefers-reduced-motion` は利用者側の設定なので、それだけでは足りない
  - 止めた状態はブラウザに保存し、次に開いたときも止まったままにする
  - `prefers-reduced-motion: reduce` のときは、最初から止まった状態にする
- 数秒で終わり、クリック・キー操作で飛ばせる演出（イントロ・開閉の演出）は、止める手段の対象外とする。ただし `prefers-reduced-motion` では行わない（`styling.md`）
- 1秒に3回を超えて点滅させない

## 代替テキスト・名前（1.1.1 / 4.1.2）

- 画像には `alt` を書く（`content-authoring.md`・`zenn-articles.md`）。装飾の画像・アイコン・Canvas は `aria-hidden="true"` にする
- アイコンだけのリンク・ボタンには `aria-label` を付ける（例：`閉じて Home に戻る`）
- 見えている文字と `aria-label` を食い違わせない（音声入力で押せなくなるため）

## 構造（1.3.1 / 2.4.6 / 3.1.1）

- 1ページに `h1` を1つ置き、見出しのレベルを飛ばさない
- 複数ある `<nav>` には `aria-label` で区別できる名前を付ける（例：`セクション`、`前後のセクション`）
- `<html lang="ja">` を保つ。英語だけの見出し・ラベルに `lang` は付けない（固有名詞・短い語のため）

## 確認

- 新しい画面・部品を作ったら、キーボードだけで操作できるか確かめる
- コントラストは、上の表の透明度に収まっているかで確かめる。表にない色を使うときは計算して確かめる
