## Overview

Claude Code でサブエージェントを並列に動かすと、どのエージェントが何をしていて、どこで止まっているのかが見えにくい。そこで、エージェント 1 つを猫 1 匹に見立てて、その様子をターミナルの全画面に描く「ねこ部屋」を作った。

- メインのエージェントは親猫、サブエージェントは子猫として、それぞれの部屋（箱）に入る。Claude Code のタブごとに区画を分けて、すべてのタブを 1 画面で見られる
- 依頼の親子関係を実線、引き継ぎ・レビュー・メッセージのつながりを点線で結び、猫がその線の上を歩いて部屋を行き来する
- 許可待ちや回答待ちの猫は枠が赤く点滅し、人の操作が必要な場所がすぐ分かる
- 子猫が終わると結果を、作業がひと区切りつくとその内容を、Claude Haiku が猫口調の 1 文に要約して報告する
- Claude が質問すると、いまの指示・聞いている理由・選択肢ごとの影響・おすすめを猫が解説する。子猫の調査結果も踏まえ、回答待ちの間に結果が届けば解説を作り直す

Claude Code のプラグインマーケットプレイスとして公開しており、`claude plugin install` で入れられる。

## Architecture

- 記録係の Mod（neko-agents）と表示係のビューア（neko-room）の 2 つに分けている。Mod は画面に何も描かず、猫の状態をタブごとの JSON ファイルに書き出すだけにし、ビューアが全タブのファイルを読んで描く
- Mod は Claude Code の function hooks 型プラグインで、ツールの実行やサブエージェントの起動・終了などのイベントから、猫の状態と猫どうしのつながりを組み立てる
- 書き出しは変化があったときだけ、多くても 0.5 秒に 1 回にまとめる。働いている猫がいる間は 1 分ごとに書き直して生存を示し、ビューアは閉じたタブと更新の止まったタブを表示しない
- 要約と解説に送るのは最近の指示・直前の説明・質問だけにし、会話全体は送らない。子猫の結果の本文は Mod の中だけに持ち、ファイルには書き出さない
- ビューアは Bun で動き、図のレイアウト（猫の配置と線の引き方）を描画から切り離して単体テストしている
